# Muhammad Ariel Rizky — Portfolio

A dark-luxury personal portfolio built with Next.js, TypeScript, React, and custom CSS.

## Run locally

1. Install Node.js LTS.
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Before publishing

Review the project descriptions and skill/tool list in `app/page.tsx`. Edit them so every project, skill, and claim accurately reflects your work and current experience. Project entries are portfolio summaries, not claims of completed production deployments.

## Deploy free on Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to https://vercel.com using GitHub.
3. Choose **Add New → Project** and import your repository.
4. Keep the detected Next.js settings and choose **Deploy**.
5. Vercel will assign a public `*.vercel.app` address.

Vercel Hobby is intended for personal, non-commercial use. Review Vercel's current plan terms before deployment.
